# 货物图鉴

[返回首页](README.md)

底价是中等品相的估值；实际卖多少还看品相、当天行情、战事、买家是谁（见[经营](shop.md)）。占格是在库房、陈列柜里占的宽×高。

- **仙门禁物**、**魔宗禁药**：摆出来招执法堂（见[执法堂与巡查](law.md)）。
- **可加…**：能偷偷掺进别的货里（见[人物与派系](people.md)）。
- **战时涨价**、**奢侈**：跟着战事涨落（见[时令与战事](calendar.md)）。
- **刻意去弄**：想凑齐配方时能主动去的来路。大致上，**低阶**的货买得到，或者在不大危险的地方拾荒就有；**中阶**的要去险地（标“险”的）翻；**高阶**的靠功勋兑换和机缘。没写来路的，要么自己用设备做（见[设备与配方](production.md)），要么只能等客人来卖、等机缘。每一种配方、加料，只要刻意去凑都做得成——这一点由 `tools/playtest/behaviors.mjs --check` 用只走正当渠道的模拟玩家验证。
