# 执法堂与巡查

[返回首页](README.md)

## 关注

顶栏的执法堂关注涨到 **{{ T.probe.heatLimit() }}**，你就被锁拿入狱（手里有护身符能免一次）。

**会涨的**：

- 陈列柜里摆着仙门禁物、魔宗禁药（每夜都涨，摆得越多涨得越多），被巡视的管事或客人看见还会举报。
- 跟仙门的人做买卖；卖魔宗禁药；收仙门禁物。
- 卖出去的赃物被原主认出来。
- 不逢鬼市的日子去鬼市。
- [[upgrade:hijack]]偶尔被人发现。
- 打点不成、加料被识破、杀人被看见、控心被识破。

**会退的**：每夜自己退一点，魔宗声望越高退得越快；巡查来了什么也没查到，关注大降；向执法堂举报通缉犯、卧底也能降一些。

## 巡查

- 关注越高，巡查越常来；难度、星期、战事、房东的态度都会改变频率。你结交的人里有耳目，会提前一晚捎来风声。
- 巡查翻的是库房、陈列柜和地上；[[upgrade:hidden]]和柜台不搜。陈列柜里的禁物一定被翻出来，别处的不一定。
- 查到禁物、赃物会没收并罚款，关注再涨；交不出罚款更糟。

## 打点

巡查进门前可以塞钱了事。价钱随关注涨：关注为零时 {{ T.probe.bribe(0) }} 灵石，每多一点关注贵 {{ T.probe.bribe(1) - T.probe.bribe(0) }} 灵石，关注 {{ 50 }} 时要 {{ T.probe.bribe(50) }} 灵石。

执法堂的巡查、征调使这些人各有贪念与操守：打点分三档并标出成算，给足了规矩就淡了，给少了对方觉得受辱，关注反而上升。清官要价高，收惯了的越来越好说话。

## 禁物

- **仙门禁物**、**魔宗禁药**在[货物图鉴](items.md)里有标记，别摆进陈列柜。
- 赃物（[[dealer:ghost]]收赃）过几夜就淡了，原主循着神识烙印追来的除外——[[tech:erase]]能抹掉烙印。
