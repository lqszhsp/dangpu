# 魔门当铺·来路不明 攻略

你在魔道宗门血煞宗的杂役区开了一间当铺。租子一期比一期高，攒够灵石买下铺契就算赢；在那之前别被执法堂锁走，别欠租被撵，也别把命丢了。

> 这份攻略里的数字、名称、配方都由程序从游戏代码里取出来，并且和代码对过账：代码一改，攻略就得重新生成，对不上会被检查拦下。所以这里写的就是游戏眼下的样子。

## 怎么赢

- 寻常难度下铺契要 **12000 灵石**（其他难度见[开局与难度](start.md)）。故事里帮对了人，铺契还会降价。
- 买下铺契那一刻，过户的规费会把你剩下的灵石和铺里的货一并刮走：铺子是你的了，人又一贫如洗。

## 怎么输

| 结局 | 怎么来的 |
| --- | --- |
| **锁拿入狱** | 执法堂关注涨到 100（见[执法堂与巡查](law.md)） |
| **扫地出门** | 租子交不上，宽限 2 日后还是交不上（见[经营](shop.md)） |
| **伤重不治 / 毒发身亡** | 受伤到第三重、中毒到第三重时不治（见[伤毒、求医与死亡](health.md)） |

手里有护身符的，上面任何一种都能免一次。护身符是你帮过的人混出头以后回来报恩给的（见[人物与派系](people.md)）。
