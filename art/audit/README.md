### 生成时的约束

- 妖族都是**人形全身立绘**，以一至三处原形特征区分；龙凤不是独立兽体、骑宠或背后一只动物。狐狸、虎、蛇不重复立新物种。
- 魔修通过工种塑造服装、工具、身姿和磨损。体型、疤痕或不对称外貌不等于反派标记；诱惑／性感仅用于明示成年的独立角色，少年、少女采用生活化服装、站姿和构图。孕妇是成年人物的生命阶段标签，不是年龄段，也不和性感类别叠用。
- 保留真人写实、全身正面、暖红主光与冷紫轮廓光，按现有项目设计区分 `_f1`/`_f2` 换演员与六种同人状态。建议先审 15 张底图（原三族 9 + 仙门 6），过审后才按各自底图做已有状态；若 55 张均做齐，新增 **385 张（55 底图 + 330 状态图）**，正式人物图由 294 张增至 **679 张**。实验 14 张另计，此数不是已排队数量。
- 秋篆的符箓修补、照微的夜巡提灯在实验中已经有成套图，不另起相近成人角色重复生图；少女符铺学徒、老妪魂灯守用年龄与工具明确区分。后续每批先对 `清单 ID / 文件 / 实验完成记录 / 进行中计划`，只去重后新增；产物先放独立实验目录。

复核方法：从项目根目录运行 `python3 game/art/audit/character_inventory.py`。脚本只读正式清单、原图、运行图、游戏女性映射、生成日志与实验状态，验证图像格式、解码、运行图透明通道和高度，再重建本目录的 CSV、JSON 与联系表。
